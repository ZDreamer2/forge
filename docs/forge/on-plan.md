build tooling and aggregate acceptance. Read [architecture](../architecture.md) for
server/UI ownership and [README](../../README.md) for supported commands.

This parent codebase owns package/configuration/tools/docs outside the nested
server and UI roots. [Server planning](../../server/docs/forge/on-plan.md) and
[UI planning](../../ui/docs/forge/on-plan.md) supply their distinct runtime guidance.
